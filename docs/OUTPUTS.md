# Итог проверки: что получает пользователь

Три независимых результата, в окне плагина отмечаются галочками в любой комбинации:

1. **Excel** с замечаниями.
2. **PDF** листов с пометками.
3. **Копии листов с пометками** в модели.

## Правила

- Пометки ставятся только на копиях видов на новых листах «Проверка_...»; оригиналы не меняются.
- Пометки только аннотации: текстовая заметка с номером замечания, выноска и рамка из линий детализации
  вокруг элемента. **Облака ревизий не используются** (они меняют таблицу ревизий).
- Все созданные элементы помечаются префиксом «НК» и особым типом, удаляются одной кнопкой.
- Только Excel: копии и пометки не создаются, модель не меняется.
- PDF без копий в модели: копии создаются, экспортируются в PDF и сразу удаляются.
- Копии и PDF: PDF делается с копий, копии остаются.
- Номера замечаний в Excel, на листах и в PDF совпадают.

## Ограничения

- Экспорт PDF из Revit доступен с версии 2022.1; без него нужен PDF-принтер.
- Копируются графические виды (планы, разрезы, фасады, 3D); спецификации и легенды на листах не копируются.
