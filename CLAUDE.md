# revit-norm-check-and-comments

Плагин для Revit 2022 (C#, .NET Framework 4.8), проверяет планы по нормам и выгружает замечания в Excel.
Структура проекта и план: `README.md`, `docs/RULES.md`, `docs/OUTPUTS.md`.

Если задача про составление правил по нормам, следуй `docs/EXTRACT_RULES.md`: правила только по тексту норм,
дословные цитаты, `approvedBy` не заполнять, цитаты проверять `tools/verify_rules.py`.
