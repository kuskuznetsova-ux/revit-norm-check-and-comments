# revit-norm-check-and-comments
check layouts meet with building codes

## Плагин (Revit 2022)

Каркас: кнопка «Проверка норм» на вкладке «Надстройки», окно с выбором проверок
(список в `docs/RULES.md`). Три группы проверок: A нормы, B стандарты компании, C состав и оформление АР стадии П; для каждой своя папка с PDF. Пути и выбор запоминаются в
`%AppData%\RevitNormCheck\settings.json`. Сами проверки и выгрузка в Excel пока не реализованы.

Сборка (нужны .NET SDK и установленный Revit 2022):

```
dotnet build src/RevitNormCheck/RevitNormCheck.csproj -c Release
```

Если Revit стоит не в `C:\Program Files\Autodesk\Revit 2022`, добавьте
`-p:RevitInstallDir="D:\путь\к\Revit 2022"`.

Установка: положите `RevitNormCheck.addin` в `%AppData%\Autodesk\Revit\Addins\2022\`,
а содержимое `bin\Release\net48\` в папку `RevitNormCheck` рядом с ним.

## Как работает проверка

Кнопка «Проверить» проходит по выбранной области (текущий вид или лист, выбранные листы и виды,
вся модель) и сохраняет отчёт `.xlsx`: результат, лист, вид, этаж, элемент, ID, факт, требуется,
документ, пункт, цитата, координаты. Требования берутся из `rules.json` в папке с нормами
(формат: `docs/RULES_FORMAT.md`). Реализованы A.1.1 (ширина дверей), A.1.3 (ширина маршей),
A.1.4 (открывание дверей); остальные проверки попадают в отчёт как «Не реализовано».
Модель проверка не меняет.

## Нормы: корпус и сверка

- **Подготовить нормы:** разбирает все PDF в папке с нормами (включая подпапки) на пункты и сохраняет `corpus.json`
  в этой папке. Неизменённые PDF при повторной сборке не перечитываются. Сканы без текстового слоя распознаны
  не будут, плагин сообщит об этом.
- **Поиск по нормам:** поиск по тексту пунктов, кнопка копирует цитату с документом и пунктом.
- При каждой проверке утверждённые правила сверяются с корпусом: если пункта нет или цитаты в нём нет, правило
  не применяется, а в отчёте появляется строка «Правило: проверить» или «Правило: устарело».

Для чтения PDF проект использует NuGet-пакет `PdfPig` (версия 0.1.x); при установке копируйте в папку плагина
всё содержимое `bin\Release\net48\`, а не только `RevitNormCheck.dll`.
